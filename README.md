# Astra Educational Consultancy — Website

Official website for **Astra Educational Consultancy** (Astra International Education Pvt. Ltd.), a study abroad consultancy based in Nepal.

🌐 **Live Site:** [https://astrainternationaledu.edu.np](https://astrainternationaledu.edu.np)

---

## 📖 About

Astra Educational Consultancy helps Nepali students plan their international education journey — from career counselling and university selection to applications, visa guidance and pre-departure support.

This website provides:
- Information about services and study destinations
- A free consultation inquiry form (via WhatsApp and email)
- Contact details and social media links
- SEO-optimized pages for search visibility

---

## ✨ Features

- **6 responsive pages** — Home, About, Services, Destinations, Contact, Inquiry
- **Modern design system** — Inter + Manrope typography, refined green/cream/dark palette
- **Hero image slider** — Rotating destination cards with auto-play
- **WhatsApp float button** — Instant chat access on every page
- **Inquiry form** — Prepares a WhatsApp message or email draft automatically
- **Centralized social links** — Update once in `main.js`, changes everywhere
- **SEO optimized** — Unique meta tags, Open Graph, Twitter Cards, JSON-LD schema
- **Mobile-first** — Fully responsive down to 320px
- **Accessibility** — ARIA labels, semantic HTML, focus states
